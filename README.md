# Tic-Tac-Toe (Python + tkinter)
A classic two-player Tic-Tac-Toe game built with Python's built-in tkinter library.
Players take turns marking X and O on a 3×3 grid. The game detects wins by checking all possible rows, columns, and diagonals, highlights the winning line in green, and announces the winner via a popup.

# Features

Clean graphical interface using tkinter buttons
Alternating turns between X and O
Win detection with visual feedback (winning cells turn green)
Simple turn indicator label
Game exits after a win (can be extended for replay)tic-tac-toe
# How to run
python tic_tac_toe.py
